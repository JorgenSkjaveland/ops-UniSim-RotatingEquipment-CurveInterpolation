# Ops-CompressorMapInterpolationForUniSim
Convert a drawn compressor map on the form: 

$E (H, Q, rpm)$

$E = Efficiency$
$H = Head$
$Q = Volumetric Flow$
$rpm = Revolutions per Minute$
